Designed for records that matter.

The free build runs locally and on static hosting. The production path maps private evidence to IBM Cloud Object Storage, metadata to Cloudant, APIs to Code Engine, and document extraction to watsonx.ai — with IBM Z/LinuxONE as the confidential, resilient target.
